# Alias command routes

## Contents

Patch, handle-change, and retirement proxy routes for one alias.

## Ownership

The Astro server boundary validates the route shape and forwards only approved request data.

## Extension rules

Add commands only after their contract and Worker operation are registered.

## Conventions

Preserve CSRF, idempotency, strong version, and disclosure-safe error behavior.
