# Self identity routes

## Contents

Person identity, role-facet, and acting-context proxy route groups.

## Ownership

These routes expose only the authenticated human's server-resolved identity surface.

## Extension rules

Add a route only after its request and response contracts are locked.

## Conventions

Never derive authority from URL, client role strings, or cached acting context.
