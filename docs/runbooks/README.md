# Runbooks

## Contents

Operational procedures grouped by owning platform area.

## Ownership

The owning domain named by each runbook maintains its checks and escalation path.

## Extension rules

Add a bounded Markdown runbook under the owning area; never place credentials, private topology, or provider tokens here.

## Conventions and related material

State the trigger, safe checks, mitigation, and escalation. See [`../local-bootstrap.md`](../local-bootstrap.md) for local setup failures.
