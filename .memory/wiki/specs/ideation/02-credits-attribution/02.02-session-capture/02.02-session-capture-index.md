## Overview

The mechanism that makes the platform's thesis true: recording who did what **while it is happening**, as a byproduct of running the session rather than as an admin task afterwards. Every competitor (Jaxsta, Muso.AI, Sound Credit, Discogs) reconstructs credits later from whoever remembers; this sub-domain is the entire reason WeJammin does not have to. If it fails, domain 02 is just another credits database and `problem-statement.md`'s root cause — "absence at the point of truth" — goes unaddressed.

**Why this is a sub-domain, not a feature**: four capabilities that interact continuously. The roll call establishes who is present; the contribution log attributes work to those present; the close prompt reconciles the two and commits; attendance proof supplies the evidence tier for all of it. The roll call changes mid-session (a player leaves, a dep arrives), which rewrites what the log can attribute and what the close prompt asks.
