## Overview

The canonical record of who did what, and every surface that reads it. This sub-domain owns the credit entity itself (a person, in a role, on a work), the public discography that renders it, the traversal that makes the graph queryable ("who else has this drummer played with?"), the identifier anchoring that stops it becoming a walled garden, and the two mutation paths that keep it honest — embargo (a true credit that must not be public yet) and amendment (a wrong credit nobody is fighting over).

**Why this is a sub-domain, not a feature**: five capabilities that interact directly. Identifier resolution changes what discography renders. Embargo suppresses records that search would otherwise traverse. Amendment rewrites nodes that traversal has already cached. Merge collapses two people into one, which rewrites every discography that referenced either. None of these can be specified independently of the others.

## Decision Log

| # | Decision | Context | Source |
|---|----------|---------|--------|
| D-01 | Embargo is a first-class property of the credit record, not a discography display filter | A credit on an unreleased track is *true* and must be captured at source (the thesis) but must not be publicly visible. If embargo lived in the render layer, search traversal and the public API would leak it. It must suppress at the record. | Deep Think, this pass |
| D-02 | Amendment (agreed correction) is a separate path from dispute (contested correction) | Routing every wrong credit through an adversarial dispute case is hostile UX for the common case, which is a typo or a misattributed role that everyone agrees on. Disputes are `02.05`. | Deep Think, this pass |
| D-03 | Operator is a credited party, not a bystander | "Recorded at <Studio>" is a standard liner-note credit and studios market on their discography. The Role Matrix reflects this — Operator has a real stake in 02.01, which the sweep's provisional persona list missed. | Deep Think, this pass |
