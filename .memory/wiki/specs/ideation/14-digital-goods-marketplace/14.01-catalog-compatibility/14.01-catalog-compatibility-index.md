## Overview

How a digital product is described, and whether it will actually run on the buyer's machine. A
physical gear listing answers "what condition is it in"; a digital listing answers a
combinatorial question — format × OS × CPU architecture × DAW host × host-product dependency —
where a wrong answer produces a refund, a support ticket, and a one-star review rather than a
minor disappointment. This sub-domain owns the vendor-declared requirement data, the buyer's
declared rig, and the match between them.

**Why this is a sub-domain**: four capabilities that only have value in combination — the listing
displays the matrix; the matrix is meaningless without the host-dependency graph (a Kontakt
library that "supports macOS" still won't load in Kontakt Player); the rig profile is the
buyer-side half that turns a static matrix into a personal yes/no; and the checker is the join.
