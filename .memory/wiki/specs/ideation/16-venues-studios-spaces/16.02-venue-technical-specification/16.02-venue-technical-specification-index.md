## Overview

The structured technical and commercial truth of a **performance room**: how many people fit, what
the stage and PA are, how the gear gets in, what the room provides to the act, what deal it works
on, and whether performances in it are reported to a PRO. This is the domain's flagship asset —
the venue tech spec exists today only as an unparseable PDF on a venue website, re-asked by email
for every single show.

**Why this is a sub-domain, not a feature**: capacity, stage/PA, access, hospitality, deal model
and PRO status are distinct capabilities that constrain each other directly. The configuration
determines the stage footprint; the curfew constrains the running order which constrains the deal;
the occupancy ceiling caps the ticket allocation; the hospitality baseline is what a rider is
negotiated against. Six capabilities, mutually constraining.
