## Overview

The non-human parties: bands, labels, studios, venues, agencies and shops — entities that book, sign, own and get paid independently of whoever their members happen to be this year. This sub-domain owns the type taxonomy and what each type actually carries, the creation and lifecycle of an entity, and the transitions between types that the indie end of the industry performs constantly (a rehearsal room starts putting on gigs; a band starts a label to release its own records).

**Why this is a sub-domain, not a feature**: type determines lifecycle (a band dissolves, a shop closes, a venue goes dormant over winter), and type transitions have to preserve everything the previous type accumulated — bookings, credits, followers, reviews. The three capabilities cannot be specified independently of each other.
