## Overview

Every physical thing the act travels with or needs supplied: instruments, amps, drums, cases,
cables, spares. The manifest is the list; sourcing fills the gaps the venue can't cover; and the
load-out check is what stops the tour arriving home with eight fewer things than it left with.

**Why this is a sub-domain**: three capabilities in a loop. The manifest declares what exists; the
capability diff turns manifest gaps into sourcing needs; sourcing adds rented items back to the
manifest for that date; and the load-out check verifies the manifest is still true, feeding loss and
damage back to the gear registry. Declare → source → verify → correct, each stage feeding the next.

## Decision Log

| # | Decision | Context | Source |
|---|----------|---------|--------|
| D-01 | The manifest is built from the gear registry (15), not typed | Domain 15 already holds a musician's gear with serials, photos and proof of ownership. Re-typing "Fender Precision Bass" into a tour manifest creates a second truth about the same object — and the registry's version is the one with the serial the carnet needs and the insurer wants. The manifest *references* registered items. | Agent cross-domain analysis, 2026-07-16 |
| D-02 | Sourcing uses the gear rental rail, not a new one | A backline shortfall is a rental need. Domains 13/16 already handle gear transactions and venue-supplied equipment. Same rationale as local crew hire (18.08 D-03): don't fork a marketplace. | Agent classification, 2026-07-16 |
| D-03 | Ownership is per-person, not per-band | The bassist's rig belongs to the bassist. A band-owned manifest gets loss, insurance and customs wrong — three domains where "whose is it?" is the entire question. | Agent, 2026-07-16 |
| D-04 | Load-out verification is a first-class feature, not a checklist | Gear goes missing at every show. The manifest already exists, the load-out is already happening, and the check costs seconds — but only if the manifest is real data rather than a printout. | Agent Deep Think, 2026-07-16 |
