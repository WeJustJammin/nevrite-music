## Overview

The three linked documents that tell a room how to put the show on stage: where everyone and
everything physically stands, what plugs into which console channel, and who hears what. Today they
are three separate artifacts — a drawing, a spreadsheet, and a paragraph in the rider — maintained
by different people and reliably contradicting each other by show day.

**Why this is a sub-domain**: three capabilities that generate and constrain each other. The input
list derives from what's on the plot (a source with a mic is a channel); the monitor spec references
the input list (a mix is a set of channels sent to a position on the plot); and the plot's positions
are what a monitor mix is *for*. Change the plot and the other two are wrong — which is precisely
why they drift apart when kept as separate files.

## Decision Log

| # | Decision | Context | Source |
|---|----------|---------|--------|
| D-01 | The input list derives from the stage plot, not the other way round | A source exists physically before it exists as a channel. Deriving the list from plot items eliminates the classic "the plot has 3 vocal mics, the input list has 2" contradiction by making it structurally impossible. | Agent Deep Think, 2026-07-16 |
| D-02 | Separated from the technical rider (18.04.01) | The rider says *what the venue must provide*; these say *what the act brings and how it connects*. Different data, different diff targets. Duplicating the input list into the rider would create two channel counts. | Agent classification, 2026-07-16 |
| D-03 | The patch column is venue-owned; the rest is act-owned | The act cannot know which stage box input is free in a room they've never seen. Co-authorship on one column is correct and is the only place in the domain where a venue writes into an act's document. | Agent, Operator persona analysis |
| D-04 | Monitor spec is a child here, not in the rider | A mix is defined as channels (from the input list) sent to a position (on the plot). It cannot be authored anywhere those two don't exist. | Agent, 2026-07-16 |
