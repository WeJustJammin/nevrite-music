## Configuration Classification Matrix

| Value class | Example | Product-editable? | Owning control plane | Required change gate |
|---|---|---|---|---|
| Platform setting | default page size, announcement duration | Yes | 25.07 typed settings registry | validation, impact preview, version, rollback |
| Party/user preference | locale, notification preference, permitted page emphasis | Yes, scoped | owning domain + registered setting/preference contract | acting authority, scope validation, audit as classified |
| Editorial content | page copy, navigation label, SEO description | Yes | 25.01–25.05 | revision, preview, workflow, publish |
| Feature flag | staged release cohort | Yes, bounded | 25.07 flag registry | owner, expiry, fallback, rollout evidence |
| Experiment | approved variant allocation | Yes, bounded | 25.07 experiment registry | consent/privacy review, metric, expiry |
| Emergency kill switch | disable vulnerable non-core capability | Yes, privileged | 25.07 emergency controls | step-up, incident link, safe fallback, postmortem |
| Governed domain rule pack | partner loudness profile, jurisdiction capability profile | Not as an ordinary setting | owning domain rule-pack workflow | specialist validation, version/effective date, domain approval |
| Deployment/runtime config | binding name, endpoint, queue consumer concurrency | No CMS edit | deployment environment | code review, CI, deploy approval |
| Secret | OAuth secret, service-role key, signing key | Never | secret manager | least privilege, rotation, access audit |
| Contract/invariant | ledger balance, mandate semantics, legal floor, state transition | Never | code + contract + migration workflow | originating-stage decision and full cascade |
| Derived value | effective entitlement, reputation, calculated settlement | Never directly | owning domain computation | recompute from canonical inputs |

**Release gate:** every operator-changeable product value must have a definition manifest entry. Every remaining literal must classify as code invariant, protocol constant, derived value, test fixture, or presentation copy owned by content. Unclassified product literals block release.
