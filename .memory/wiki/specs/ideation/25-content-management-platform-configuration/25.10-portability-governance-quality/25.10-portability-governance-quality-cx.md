## Confirmed Cross-Cut Contract

For every pair above:

1. Source and target own separate immutable versions; references carry version IDs.
2. Canonical source commits with an outbox record; target retries idempotently.
3. Both permissions apply and the narrower result wins.
4. Sensitive changes notify owners using identifiers, not protected payloads.
5. Optimistic checks reject stale activation and preserve candidate work.
