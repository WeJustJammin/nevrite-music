## Overview

How a published opportunity reaches the person who should see it — by pull (the board: browse,
search, filter, save) and by push (alerts against a saved intent). The parent domain calls this the
domain's own justification: "it is arguably the #1 reason a working musician opens the app: alerts
carry money and dep gigs are won in minutes." Matching is the engine both paths share, and it is
where this domain earns its differentiation — availability-aware, geo-aware, and for dep calls,
material-aware.

**Why this is a sub-domain, not a feature**: four capabilities that feed each other directly. A
saved search *is* an alert subscription — the board and the alert pipe are two renderings of one
intent. Matching supplies the ranking for both. And material-aware matching is a distinct engine
that only fires for one type but changes what the whole domain is worth.
