## AC211 real outcome shape and the Delete-only contract (local only, unmerged)

  object. The earlier "real provider date shape stays unverified" note is
  superseded: the date, count, and dimensions gates are exercised and passing.
- The remaining failure was the outcome gate. The redacted diagnostic reported
  `ReadMessage` and `WriteMessage` with `outcomeClass: other_string` and
  `rejectionGate: outcome_shape`, while a `DeleteMessage` row reported
  `dlq` and was accepted. No raw outcome value was retained and none is
  asserted here.
- Cloudflare documents the `outcome` dimension as applicable only to
  `DeleteMessage`
  (https://developers.cloudflare.com/queues/observability/metrics/), which
  makes the read/write value inapplicable rather than an error. The shared row
  classifier now accepts an absent, null, or bounded (64-character) string
  outcome on read and write rows, never counts it, and still rejects a
  non-string, an over-long string, or the `dlq` marker on a non-delete row.
  `DeleteMessage` keeps its closed `success`/`dlq`/`fail` vocabulary, so
  `dlq` on a delete row remains the only DLQ evidence the collector accepts.
  No date, count, or dimensions gate was relaxed.
